1. if __name__ == "__main__":
이건 주로 함수를 테스트해보고 싶을 때 사용하는 함수이다.
사용하는 이유는 테스트 코드를 작성하면 테스트 이후 지워야 오류가 발생하지 않는데 
위의 코드를 사용함으로써 지우지 않아도 언제든지 내가 함수를 테스트 해보고 싶을 떄 테스트를 할 수 있다.
그리고 코드를 지우면 되지 않냐라는 의문을 가질 수 있는데 지우면 다음에 내가 테스트 할 때마다 저 코드를 적어야 해서 번거롭기 때문이다.
    
2. git add 파일이름.확장자
파일을 스테이징 할 떄 확장자까지 적어줘야 한다.

3. 파일 실행시 오류가 발생하는 이유는
파일을 실행 할 떄 파일 안에 아무런 문제가 없는데도 실행 버튼을 누르면 오류 코드가 발생하는 때가 있다.
이때는 현제 내가 있는 경로에서 파일을 실행했을 때 파일들이 상위의 파일을 활용하는 부분이 있으면 오류가 발생한다.

4. 매인 파일에 들어가야 할 내용
보통 메인 파일은 가볍게 만들기 위해서 

    # 게임 객체 생성 (생성자 내부에서 state.json 파일 자동 로드)
    game = QuizGame()

    # 게임 실행 (메인 메뉴 루프 시작)
    game.run()

이런식으로 동작을 하는데 이때 궁금증이 왜 객체를 생성해야 할까라는 의문이 있었다.
객체는 2가지의 역할을 한다 
첫 번째는 매번 정보가 필요할 떄 마다 불러올 필요가 없게 임시저장해두는 캐시같은 역할 
두 번째는 커드가 커졌을 떄 덜했갈리게 구조적으로 만드는 역할이다
